## 2. 흐름

```
곡 구간(이미 있음: data/song_work/cNN_mix.wav, separate.cut_clip)
  → STT 구간 시각 포함(stt.recognize_segments, medium, 원곡 경로, VAD 끔)
  → 줄 나누기(song_lines.py: 구간 = 줄 기본, 길면 단어 시간으로 분할, 너무 짧으면 병합)
  → 줄별 재생으로 귀로 확인(노트북)  ← 사용자
  → 가사 수정(수정 전/후 기록)         ← 사용자
  → lines.json 저장(data/song_practice/<id>/)
  → 줄마다 표준 발음 음성(tts.py, 캐시)
  → (#32) 줄 단위 보컬 조각 / 연습
```

## 4. 저장 형식 설계 (초안)

`data/song_practice/<구간 id>/lines.json` (git 제외):

```json
{
  "clip_id": "c05", "song_file": "(파일 이름은 저장하지 않음)", "start": 20.0, "duration": 20.0,
  "stt": {"model": "medium", "vad_filter": false, "temperature": "default", "seconds": 0.0},
  "lines": [
    {"no": 1, "start": 0.0, "end": 3.2, "stt_text": "…", "text": "…", "edited": false, "status": "candidate|confirmed|dropped",
     "avg_logprob": -0.4, "no_speech_prob": 0.01, "compression_ratio": 1.2, "tts_path": null}
  ]
}
```
- `stt_text`는 **원문 그대로**, `text`가 연습에 쓰는 수정본(수정 전/후를 같이 남김). 가사를 고쳤는지 `edited`로 구분.
- 곡 파일 이름은 저장하지 않고 곡 번호·시작·길이만 남깁니다(`clips.csv`와 같은 기준).

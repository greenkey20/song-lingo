# 작업 일지 (song-lingo)

이 문서는 하루 작업을 짧게 남기는 일지입니다. 사용자가 Notion 일일 기록에 복사해 쓰고, 강사님과의 면담 때 보는 용도입니다. 양식은 계획서 9장의 일일 기록(날짜 · 한 일 · 막힌 점 · 내일 할 일 · 질문)을 따릅니다. 판단의 근거와 옵션 비교는 `프로젝트_안내_및_주제_검토.md`에 있고, 이 문서는 "무엇을 했고 각 파일이 무엇인지"만 적습니다.

> **AI가 쓴 코드를 이해하는 법**: 아래 파일 표의 **"수업과의 관계"** 열에서 '수업 코드 재사용'은 수업 자료로 복습하면 되고, **'수업에 없음'** 은 코드 주석과 이 표를 읽으며 따로 익힐 부분입니다. 새 코드에는 수업과 다른 부분을 주석에 `[수업에 없음]`으로 표시합니다.

## 2. 파일별 역할

| 파일 | 하는 일 | 수업과의 관계 |
| --- | --- | --- |
| `scoring.py` | 문장 정규화 → 편집 거리 표 → 역추적으로 일치·치환·삭제·삽입 구분 → 오류율(WER/CER)과 틀린 부분 표시 | 수업의 WER/CER 개념 + 직접 구현(`WER_CER_이해하기` 보충). 동률 처리 규칙은 수업에 없음 |
| `tts.py` | 문장 → OpenAI TTS 호출 → wav 저장(캐시). 문장 번호·직접 입력 조회 | 013 OpenAI API 호출 방식 재사용. 캐시와 호출 횟수 기록은 수업에 없음 |
| `stt.py` | faster-whisper `tiny`를 CPU에서 로딩(한 번만), 녹음 파일 → 인식 문장, 단어별 시간 | 7강 코드 재사용. `word_timestamps`·VAD 옵션은 수업에 없음 |
| `align.py` | 채점 결과의 틀린 연속 칸을 한 덩어리로 묶고, TTS·내 녹음의 시간 구간으로 변환 | **수업에 없음**(직접 설계) |
| `audio.py` | 어떤 녹음 파일이든 16 kHz 모노 파형으로 변환 | wav 경로는 lesson04 4-D와 같음. wav 외 형식(PyAV)은 수업에 없음 |
| `theme.py` | 그래프 색·스타일 공통 설정(초록 계열) | 수업에 없음(검토 문서 8.26) |
| `practice.ipynb` | 시연 화면. `practice(문장, 모드)`, 소리 그림(STFT·Log-Mel), 틀린 구간 표시 | STFT·Log-Mel 함수는 lesson04 복사. 나머지는 직접 작성 |
| `spike/server.py`, `spike/index.html` | 브라우저 녹음 → 서버 → Whisper → 채점을 한 번에 점검하는 임시 화면 | 수업에 없음(FastAPI, MediaRecorder). 최종 UI가 아니라 점검용 |
| `tests/` | `scoring`, `tts/stt`, `align`, `audio` 단위 테스트(표준 라이브러리 `unittest`) | 수업에 없음 |
| `scripts/scan_outputs.py` | 커밋 전에 노트북 출력의 오디오·개인 경로·key를 검사 | 수업에 없음 |
